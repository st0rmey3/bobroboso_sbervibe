## Бонусы (до +10, только при полностью закрытом обязательном объёме)
- система сама сообщает соискателю, чего не хватает, и просит дослать;
- уверенность разбора по каждому полю — оператор видит, что перепроверить первым;
- сопоставление данных между документами одного человека (ФИО в паспорте и патенте расходятся → замечание);
- документы, которые скоро истекают, + выгрузка списка;
- выгрузка карточки соискателя в файл для кадров;
- очередь в цифрах: ждёт / разобрано / среднее время разбора;
- обезличивание или ограничение доступа к файлам с ПДн;
- история по заявке: кто и когда что менял.

## Снятие с конкурса (любое из)
- ответы подогнаны под конкретные тестовые файлы вместо реального разбора;
- данные только в памяти процесса, в файле рядом с кодом или только в очереди — без настоящего хранилища;
- рабочее место оператора показывает заготовленные данные, не связанные с реальными заявками;
- приём подтверждается, но разбор не выполняется (сразу «готово» без обращения к модели);
- обработка выполняется в момент отправки, человек ждёт её завершения;
- работа теряется при перезапуске сервера;
- данные людей доступны без входа (прямая ссылка, запрос в обход входа, форма входа ничего не проверяет);
- секреты и ключи в репозитории;
- команда не может объяснить работу своего решения.
