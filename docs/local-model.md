# Переход на локальную модель (пошагово)

> Черновик-шаблон. Значения `<<…>>` заполняются по реальным замерам на стенде (задача T-006).

Зачем: заказчик хочет полностью отказаться от передачи документов во внешние сервисы. Локальная модель
работает на своём компьютере, документы никуда не уходят. Переключение — только настройкой в `.env`, код не меняется.

## 1. Что нужно
| | Минимум (проверено) |
|---|---|
| Видеокарта | NVIDIA RTX 5060, 8 ГБ видеопамяти |
| ОЗУ | <<ГБ>> |
| Диск | ~6 ГБ под модель `qwen2.5vl:7b` |
| ОС | <<Windows 11 / Linux>> + Docker Desktop |

Без видеокарты модель тоже запустится, но разбор одного файла займёт <<время на CPU, если мерили>>.

## 2. Установить Ollama и скачать модель
1. Скачать и установить Ollama: https://ollama.com/download (запускать нативно, не в Docker — так работает видеокарта).
2. Скачать модель, которая читает изображения и помещается в 8 ГБ:
   ```bash
   ollama pull qwen2.5vl:7b
   ```
3. Проверить, что модель отвечает:
   ```bash
   ollama run qwen2.5vl:7b "Ответь одним словом: работает?"
   ```

Вариант для Linux-сервера без установки Ollama: `make up-local-llm` поднимет Ollama в контейнере
и скачает модель; тогда в `.env` указать `OLLAMA_URL=http://ollama:11434`.

## 3. Переключить систему
В файле `.env`:
```
LLM_PROVIDER=ollama
OLLAMA_MODEL=qwen2.5vl:7b
OLLAMA_URL=http://host.docker.internal:11434
OCR_PROVIDER=none
```
Перезапустить бэкенд и воркер:
```bash
docker compose up -d backend worker
```

## 4. Проверить, что работает
1. `curl http://localhost:8000/api/health` → в ответе `"llm_provider": "ollama"`.
2. На http://localhost:3000 загрузить документ — статус дойдёт до «Готово», в рабочем месте оператора видны поля.
3. В логах воркера (`docker compose logs --tail 20 worker`) — строки `document … → done`.

Вернуться на внешнюю модель: `LLM_PROVIDER=openai` и снова `docker compose up -d backend worker`.

## 6. Что меняется при переходе
| | Внешний сервис | Локальная модель |
|---|---|---|
| Железо | не нужно | GPU от 8 ГБ (RTX 5060 и выше) |
| Скорость | ~11 с на файл, 8 файлов параллельно | <<по замерам>> |
| Качество | <<по замерам>> | <<по замерам>>; сомнительные поля уходят оператору на проверку |
| Стоимость | оплата за запросы | разовая покупка железа + электричество |
| Приватность | документы уходят во внешний сервис | документы не покидают компьютер |
