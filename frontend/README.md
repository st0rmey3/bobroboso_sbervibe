# Интерфейсы приёма документов

React-приложение работает с серверным API: `/` — соискатель, `/operator` — оператор,
`/operator/applications/:id` — сверка оригиналов и полей, `/operator/processing` — очередь,
`/operator/expiring` — истекающие и просроченные документы с выбором периода.
Страны, виды документов и названия полей приходят с сервера. Типы HTTP-контракта генерируются из OpenAPI.

## Разработка и сборка

Нужен Node.js 22 или новее. Команды выполняются в папке `frontend`:

```bash
npm ci
npm run gen:api
npm run build
npm run dev
```

Dev-сервер доступен на http://localhost:5173 и направляет `/api` на http://localhost:8000.
Для реальных сценариев нужны backend, worker и Keycloak; запуск всей системы описан в корневом README.
Авторизация оператора — OIDC с PKCE; сервер проверяет токен независимо от защиты маршрутов в браузере.

## Проверки интерфейсов

```bash
npx playwright install chromium
npm test
npm run format:check
```

Для форматирования используйте `npm run format` (Prettier, ширина строки 120).
Сгенерированный `src/api/schema.d.ts` исключён из форматирования.

22 браузерные проверки охватывают выбор страны и ширину 375 px, создание заявки,
загрузку нескольких файлов, обновление статусов, восстановление после перезагрузки,
отказ для дубликата, отсутствие ключа заявки, перенаправление на Keycloak с PKCE,
сверку оригинала, сохранение поля в исходный документ, повторный разбор, фильтры и очередь.
Также проверяются названия полей документов вне каталога стран, CSV карточки и списка сроков,
Bearer-заголовок, сохранение байтов UTF-8 BOM и кириллицы, имя скачанного файла,
просроченные и истекающие сегодня документы, смена периода без старых строк,
повтор после ошибки, ответы 401/403 и HTML вместо CSV, завершение сеанса без запроса к API.
Предупреждения о расхождениях между документами показываются перед полями карточки;
при пустом списке блок отсутствует. Названия полей в истории берутся из серверного слота,
даже если вид документа отсутствует в каталоге стран.
Для отправки комплекта проверяются выбор файлов без немедленного запроса, общая кнопка отправки,
отсутствие `declared_type` у «Другого документа», новый слот из ответа сервера, подтверждение с номером заявки,
частичный отказ и повтор только непринятых файлов, удаление выбранного файла и запрет отправки в закрытую заявку.
История оператора показывает событие просмотра оригинала с русской подписью и именем файла.

Синтетические ответы API и тестовый токен используются только в `tests/`.
Они проверяют поведение интерфейса и запросы, но не доказывают качество модели,
проверку JWT сервером или работу живого Keycloak. Эти проверки и открытие CSV в настоящем Excel
выполняются отдельно на стенде.
Снимки интерфейса и трассы неудачных проверок находятся в игнорируемой папке `test-results/`.

## Что важно для защиты

Ключ соискателя хранится в localStorage этого браузера; ссылка с номером заявки сама по себе не даёт доступа.
Выбор файла добавляет его в список без отправки: можно собрать комплект из нескольких блоков и убрать лишнее.
Кнопка «Отправить комплект» отправляет выбранные файлы параллельно; у «Другого документа» вид не указывается,
его определяет серверная модель. Новые виды и названия слотов приходят в состоянии заявки с сервера.
Подтверждение показывает первые восемь символов номера заявки и число принятых файлов текущей отправки.
При частичном отказе принятые файлы повторно не отправляются, а непринятые остаются с причиной для повтора.
Выбранные, но ещё не отправленные файлы не сохраняются после закрытия или обновления страницы.

Разбор выполняет серверный worker. Интерфейс опрашивает состояние
раз в две секунды и останавливает опрос после завершения. Ошибки загрузки показываются у соответствующего файла.

Оригиналы оператор получает запросом с Bearer-токеном, затем показывает через временный blob URL,
который освобождается при закрытии карточки. Поле сохраняется в `document_id` из объединённого результата;
при отсутствии источника используется подходящий файл слота. Во время разбора правки и повторный запуск отключены.
Сервер нормализует и проверяет правку; интерфейс показывает результат сервера и пометку оператора.

Кнопки CSV в карточке и разделе «Истекают» скачивают файл с Bearer-токеном через временный blob URL.
Содержимое передаётся без перекодирования: сохраняются серверные UTF-8 BOM, разделитель `;`
и экранирование формул. В разделе сроков CSV использует выбранный период; после выгрузки карточки
обновляется история действий. Ошибки скачивания показаны рядом с кнопкой.
